dl-helper

📥 Ouvrir les téléchargements

Les chemins sont ceux vus par Jellyfin. En Docker, c'est le chemin dans le conteneur (sur moon, /ranger est monté sur /space). Pour que « Copier » utilise des hardlinks, le dossier surveillé et les destinations doivent être dans le même montage.

🗂️ Dossiers

Dossier rempli par Syncthing. Au premier lancement, ce qui s'y trouve déjà est ignoré.
Les dossiers de tes médiathèques Jellyfin sont proposés automatiquement.

⚙️ Rangement

Copie instantanée qui ne prend pas de place quand la source et la destination sont sur le même disque.
Le nouveau film, épisode ou album apparaît dans Jellyfin sans attendre l'analyse planifiée.
Appliquée si personne n'a choisi au bout du délai. Les éléments sans suggestion ne sont jamais traités automatiquement.

🔔 Notifications

Pour les administrateurs connectés (navigateur, appli ouverte).
Rangements et problèmes visibles dans Tableau de bord → Activité.
Toucher une notification ouvre directement la page Téléchargements.

📱 Sur le téléphone avec ntfy : installe l'appli ntfy, abonne-toi à un topic au nom difficile à deviner, et mets le même nom ici.

Seulement si ton serveur ntfy demande une authentification.
Paramètres du salon → Intégrations → Webhooks → Copier l'URL.

🔍 Syncthing et détection

dl-helper demande à Syncthing s'il reste des fichiers à recevoir avant de considérer un téléchargement comme terminé. Sans Syncthing, seule la stabilité des fichiers compte.

Interface Syncthing → Actions → Configuration → Général → Clé d'API.
Si Jellyfin peut le lire, la clé API et l'ID du dossier y sont pris quand les champs sont vides.
